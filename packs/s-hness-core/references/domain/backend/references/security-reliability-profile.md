# Security and Reliability Profile

Identify assets, actors, trust boundaries, privileged actions, sensitive data, dependencies, and credible abuse or failure paths.

Make authentication and authorization enforcement authoritative on trusted boundaries. Protect secrets throughout creation, storage, use, rotation, logging, and revocation. Define validation, output handling, rate controls, audit events, and least privilege.

For dependencies define timeouts, cancellation, retry eligibility and limits, idempotency, circuit or load-shedding behavior, degraded operation, and recovery. Define health signals, service-level expectations, alerts, backup, restore, and incident rollback or forward-recovery.
