# Frontend Quality Profile

Select measurable requirements for the supported user environment.

- **Accessibility:** semantics, keyboard, focus, names, announcements, contrast, zoom, reduced motion, and assistive technology where relevant.
- **Responsive:** content priority, minimum supported size, overflow, orientation, touch targets, and localization growth.
- **Performance:** startup, interaction latency, rendering work, network and asset budgets, memory, and long-task boundaries measured with declared tools and fixtures.
- **Resilience:** loading, slow network, stale data, retries, cancellation, partial content, and recoverable errors.

Do not claim WCAG conformance, browser support, or performance improvement from code inspection alone.
