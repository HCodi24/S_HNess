# Frontend Verification Profile

- **Logic:** validation, formatting, policy, state transitions, and command construction.
- **Component:** user interaction and meaningful normal, loading, empty, error, disabled, and success states.
- **Contract boundary:** request construction, response/error mapping, cancellation, and stale data using controlled doubles.
- **Browser workflow:** navigation, forms, focus, visible results, recovery, and persisted state in supported browsers.
- **Quality:** keyboard, accessible names and announcements, zoom, contrast, responsive layouts, localization growth, visual stability, and measured performance.

Keep snapshots focused and never use them as the only behavior evidence. Record platform, browser, viewport, input method, theme, accessibility settings, fixture, and cleanup. A mocked API does not prove full-stack integration.
